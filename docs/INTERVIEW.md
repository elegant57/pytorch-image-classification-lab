# 面试讲解提纲

## 30 秒介绍

我把 PyTorch 学习过程中的分类实验整理成了模块化训练项目，支持 CIFAR-10/100、自定义类别目录以及三类网络选择。主流程覆盖数据增强、训练评估、TensorBoard 和检查点恢复；原始单文件练习单独保留，便于展示从基础 API 到完整训练流程的演进。

## 可以结合代码展开的点

1. `CustomNet`：32×32 输入经过三次池化变为 64×4×4，因此全连接输入为 1024；100 类自定义网络结构不同。
2. `CrossEntropyLoss` 直接接收 logits 和整数类别，无需事先 softmax；分类头维度必须等于类别数。
3. `train()`/`eval()` 控制 Dropout、BatchNorm 等层；`no_grad()` 控制梯度记录，两者职责不同。
4. 平均损失按样本数加权，避免最后一个小批次与完整批次权重相同。
5. 恢复训练需要模型、优化器、调度器和轮次；只加载模型参数不等于恢复完整训练状态。
6. 固定种子能降低随机差异，但本实现没有保存 RNG 状态，也不保证跨设备或断点逐步一致。
